# Finder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Listary-style search for files and folders inside Islet's notch. You type fragments ("isw"),
results appear immediately, and Enter, Ctrl+T, Ctrl+E, Alt+Enter or Ctrl+C open or copy the result.

**Architecture:**
- A shell script builds a cached index with `fd`. The folder index and the file index are kept apart,
  because filtering folders is fast (~30 ms) and filtering files is slower (~120–190 ms).
- `FinderService` runs `fzf --filter` on both indexes in parallel for each query. A pure ES module
  (`finder/rank.mjs`) then re-ranks the results (name match, project boost, frecency) and builds the
  action commands.
- `FinderView` is shown by the notch in a new `"find"` mode. Everything is prefixed `Finder`/`finder`
  so it can move to its own repo later.

**Tech Stack:**
- **Runtime:** Quickshell 0.3.2 with Qt 6.12 (QML, `Process`, `IpcHandler`).
- **Tools:** `fd` 10.5, `fzf` 0.74, `wl-copy`.
- **Tests:** Node 26 (`node --test`) for the `.mjs` logic.

**Spec:** `docs/superpowers/specs/2026-10-21-finder-and-today-design.md` (Part 1). The approved mockup
is `docs/superpowers/specs/mockups/2026-10-21-finder-placement.html`, option A.

## Global Constraints
- **Scope:**
  - Files and folders only; no app launching.
  - Search folders default to `~`, and hidden files are off by default.
  - Default exclusions: `node_modules, venv, .venv, __pycache__, target, build, dist, .cache, .git`.
- **Action keys:**
  - Enter: folder → file manager, file → default app.
  - Ctrl+T: terminal.
  - Ctrl+E: editor.
  - Alt+Enter: the containing folder.
  - Ctrl+C: copy the path.
- **Defaults:**
  - file manager = the xdg default;
  - terminal: auto-detect `ghostty`, then `kitty`, `foot`, `alacritty`, `konsole`;
  - editor: auto-detect `code`, then `codium`, `zed`.
- **Refresh:** reindex every 10 minutes by default, on start, and on demand (`islet find --reindex`).
- **Keybind:** `Mod+G`, written to `~/.config/niri/user-binds.kdl` inside its `binds { }` block. Do it
  only after the user confirms, and run `niri validate` afterwards.
- **Speed:** typing never stutters, and results show within about 100 ms (folders first).
- **Idle cost:** 0% CPU when Finder is closed. No timers run except the reindex timer.
- **CLI and IPC:** `islet find [query]`, `islet find --reindex`, `islet find --print <query>`; IPC
  target `finder`.
- **Separability:** new code lives in `Finder*.qml`, `finder/`, config keys prefixed `finder`, and
  `Store.db.finderHistory`. The notch only gains a `"find"` mode that hosts `FinderView`.
- **Settings:** every Finder setting is a searchable row (`win.register`) on a new "Finder" page.
- **Testing on the live machine:** before changing live settings, save each value with `islet get`
  and restore it afterwards.

## Review Focus
1. **Paths with spaces, quotes, `$`, unicode or a leading `-`** must open correctly. Actions are argv
   arrays, never shell strings, and a path is never read as an option (Task 2:
   `actionCommand keeps odd paths as single args`).
2. **Queries containing fzf operators** (`'`, `!`, `^`, `$`, `|`) or several words: words act as AND
   terms, and operator characters are matched literally rather than inverting the search (Task 2:
   `fzfQuery neutralises operators`).
3. **Results from an older query arriving after a newer one** (fast typing) must never replace the
   newer results (Task 3: request ids; checked with `islet find --print` while typing quickly).
4. **A file deleted or moved since indexing:** opening it shows "Not found — reindexing" instead of
   silently failing, and history entries for missing paths are hidden (Task 3).
5. **Index not built yet, or `fd`/`fzf` missing:** the view says "Indexing…" or "Install fd and fzf"
   instead of showing an empty list (Task 3 and Task 4).

### Task 1: Index builder

**Files:**
- Create: `finder/index.sh`
- Test: `tests/finder-index.test.mjs`

**Interfaces:**
- Produces: `finder/index.sh OUTDIR HIDDEN EXCLUDES ROOT...`.
  - `HIDDEN` is `0` or `1`; `EXCLUDES` is comma-separated.
  - It writes three files atomically (to a temp file, then `mv`) into `OUTDIR`, each holding one
    absolute path per line, without a trailing slash:
    - `dirs.txt` (folders);
    - `files.txt` (files);
    - `projects.txt` (folders that directly contain a `.git` entry).
  - Paths containing a newline are dropped.
  - It exits 0 on success and 127 if `fd` is missing.

    contains no line under `.hidden` or `.git`.

### Task 2: Ranking and actions (pure logic)

**Files:**
- Create: `finder/rank.mjs`
- Test: `tests/finder-rank.test.mjs`

**Interfaces:**
- Produces (all exported from `finder/rank.mjs`; `Entry = { path, kind: "dir"|"file", project: bool }`):
  - `fzfQuery(q: string): string`. Trims the query, keeps words as AND terms, and prefixes a word that
    starts with `'`, `!` or `^`, or ends with `$`, with a backslash so fzf matches it literally;
    `|` becomes a literal.
  - `nameMatch(q: string, name: string): { score: number, positions: number[] } | null`. A
    case-insensitive subsequence match of the joined query (spaces removed) against the base name.
    It scores higher for matches at word starts (after `-`, `_`, `.`, a space, a camelCase hump or
    the beginning), for consecutive letters, and for a match at index 0; it returns null if there is
    no match.
  - `frecency(rec: {count: number, last: number} | undefined, now: number): number`. Returns
    `count * 0.5^((now - last) / 7 days)`, or 0 when `rec` is undefined.
  - `rank(q: string, entries: Entry[], history: object, now: number): (Entry & {score, positions})[]`.
    - The score is `nameMatch` plus 40 for a project plus `15 * min(frecency, 10)` plus 10 for a
      folder, minus `0.02 * depth`. Entries whose base name doesn't match keep the fzf path match
      with a −30 penalty.
    - The result is stable-sorted by score, highest first.
  - `recent(history: object, now: number, limit = 8): {path, kind}[]`, sorted by frecency.
  - `remember(history: object, entry: Entry, now: number): object`. Returns a new object with the
    count incremented and `last` set, keeping at most 500 entries (dropping the lowest frecency).
  - `shortPath(path: string, home: string): string`. Replaces the home prefix with `~`.
  - `detect(candidates: string[], available: string[]): string`. Returns the first candidate in
    `available`, or `""`.
  - `actionCommand(action: "open"|"terminal"|"editor"|"reveal"|"copy", entry: Entry, apps: { fileManager, terminal, editor }): string[]`.
    - open: `[fileManager || "xdg-open", path]`.
    - terminal: run it in the folder (the file's parent for files). Use the terminal's own flag:
      ghostty and foot take `--working-directory=DIR`, kitty takes `--directory DIR`, alacritty
      takes `--working-directory DIR`, konsole takes `--workdir DIR`; for anything else, return
      `["sh","-c",'cd "$1" && exec "$0"', terminal, DIR]`.
    - editor: `[editor, path]`.
    - reveal: `["dolphin", "--select", path]` when the file manager is dolphin or empty and the xdg
      default is Dolphin (pass that as `apps.fileManager = "dolphin"`); otherwise
      `[fileManager || "xdg-open", dirname]`.
    - copy: `["wl-copy", "--", path]`.

- [ ] **Step 1: Write the failing tests** in `tests/finder-rank.test.mjs`:
  - `nameMatch abbreviations`: `nameMatch("isw","islet-windows").positions` deep-equals `[0,1,6]`,
    and its score is greater than `nameMatch("isw","whiskers").score`.
  - `rank prefers projects and history`: given entries `~/Projects/islet-windows` (dir, project),
    `~/x/islet_swap.txt` (file) and `~/old/isw` (dir), and history for the swap file with count 1
    from 60 days ago, `rank("isw", …)[0].path` ends with `islet-windows`.
  - `frecency decays`: `frecency({count:4,last:0}, 7*864e5) === 2`.
  - `remember caps at 500`.
  - `fzfQuery neutralises operators`: `fzfQuery("!foo") === "\\!foo"`, `fzfQuery("bar$") === "bar\\$"`,
    and `fzfQuery("  a  b ") === "a b"`.
  - `actionCommand keeps odd paths as single args`: for the path `/h/my dir/-x $y'.txt` and each
    action, the path appears as exactly one array element, and `copy` includes `"--"` before it.
  - `terminal flags`:
    - ghostty gives `["ghostty","--working-directory=/h/p"]`;
    - konsole gives `["konsole","--workdir","/h/p"]`;
    - for a file `/h/p/a.txt`, the folder is `/h/p`.
  - `shortPath`: `shortPath("/home/u/a","/home/u") === "~/a"` and `shortPath("/home/uu/a","/home/u") === "/home/uu/a"`.
- [ ] **Step 2:** Run `node --test tests/finder-rank.test.mjs`. Expected: FAIL (the module doesn't
  exist).
- [ ] **Step 3:** Implement `finder/rank.mjs` with the signatures above. Use plain ES only: no Node

### Task 3: FinderService (index lifecycle, querying, actions, IPC, CLI)

**Files:**
- Create: `FinderService.qml` (Singleton)
- Modify:
  - `Config.qml`: add defaults and `JsonAdapter` properties `finderRoots: "~"`,
    `finderExclude: "node_modules,venv,.venv,__pycache__,target,build,dist,.cache,.git"`,
    `finderHidden: false`, `finderFileManager: ""`, `finderTerminal: ""`, `finderEditor: ""`,
    `finderReindexMinutes: 10`.
  - `Store.qml`: add `property var finderHistory: ({})`.
  - `shell.qml`: add `IpcHandler { target: "finder" }`.
  - `bin/islet`: add the `find` command and its usage line.

**Interfaces:**
- Consumes:
  - `finder/index.sh` (Task 1).
  - From `finder/rank.mjs` (Task 2): `rank`, `recent`, `remember`, `fzfQuery`, `actionCommand`,
    `detect`, `shortPath`.
- Produces:
  - Properties:
    - `FinderService.query: string` (set it to search);
    - `results: var` (a list of `{path, kind, project, positions, short}`, at most 50);
    - `status: string`, one of `"ready" | "indexing" | "missing-tools" | "empty"`;
    - `indexedAt: real` (ms);
    - `counts: var`, of the form `{dirs, files}`;
    - `message: string`, a transient note such as "Not found — reindexing" or "Copied".
  - Functions:
    - `act(index: int, action: string)`;
    - `reindex()`;
    - `openRequested(prefill: string)` (a signal);
    - `apps: var`, of the form `{fileManager, terminal, editor}` with auto-detection resolved.
  - IPC `finder`:
    - `open(q: string)` emits `openRequested`;
    - `reindex()`;
    - `print(q: string): string`. It runs the query synchronously from the caller's point of view by
      waiting for both fzf runs, and returns the top 5 as `kind\tshortPath` lines. It uses the same
      code path as the UI.
  - CLI:
    - `islet find [query]` calls `ipc call finder open "$query"`;
    - `--reindex` calls `ipc call finder reindex`;
    - `--print Q` calls `ipc call finder print "Q"`.

- [ ] **Step 1: Write a failing check.** Create the script `tests/finder-live.sh`. It runs
  `islet find --print isw` and checks that the output's first line contains
  `~/Projects/islet-windows`. It also runs `islet find --print "!nothing"` and checks that the exit
  code is 0 and there is no crash. It's a manual live test against the running Islet. Run it now.
  Expected: FAIL (unknown command).
- [ ] **Step 2: Implement `FinderService.qml`.**
  - **Index location:** the index lives in `${XDG_CACHE_HOME:-~/.cache}/islet/finder/`.
  - **Building:** reindex on start, every `finderReindexMinutes`, and on request. One `Process` runs
    `index.sh`; while it runs, `status` is `"indexing"`. Results are still served from the old index
    files if they exist.
  - **Querying:** a 60 ms debounce, then two `Process`es (folders and files), each running
    `fzf --filter "$Q" < FILE | head -n 150`, with the query passed as an argument rather than
    interpolated.
    - Each query gets an increasing `_requestId`, and output from an older id is dropped.
    - The folder results are published as soon as they arrive; when the file results arrive, both
      are merged and `rank` runs again.
    - An empty query shows `recent()` filtered by an existence check (one `Process` running
      `test -e` for each path).
  - **Detecting tools:** on start, one `sh -c 'command -v …'` call detects `fd` and `fzf` (otherwise
    status `"missing-tools"`) and resolves the terminal and editor through `detect`.
  - **Acting:** `act()` builds the argv with `actionCommand` and runs it with
    `Quickshell.execDetached`.
    - Before `open`, `terminal`, `editor` or `reveal`, check `test -e`; when the path is missing, set
      `message` to "Not found — reindexing" and call `reindex()`.
    - On success, call `Store.db.finderHistory = remember(…)`.
    - `copy` sets `message` to "Path copied".
- [ ] **Step 3:** Add the config keys, the store key, the IPC handler, and the `find)` case and usage
  line in `bin/islet`.
- [ ] **Step 4: Restart and check.** Run `systemctl --user restart islet`, wait until
  `islet find --print isw` stops saying "indexing" (at most about 5 s), then run
  `sh tests/finder-live.sh`. Expected: PASS. Also run
  `for q in i is isw; do islet find --print $q & done; wait`: no errors in
  `journalctl --user -u islet -n 50`.
- [ ] **Step 5: Measure.**
  - Time `islet find --print lyrics` 5 times. Expected median: under 250 ms end to end, including
    the IPC round trip.
  - With Finder closed for 30 s, the `m2.sh`-style CPU sample (8 s) shows Islet at 0% while nothing
    plays.
- [ ] **Step 6: Commit:** `git commit -m "Finder: service, IPC and CLI"`
